## 二、系统定义

### 2.1 用户与业务功能
- **目标用户**：编译原理学习者、需要简单语言编译能力的开发者


### 4.2 类设计

#### 4.2.1 词法分析模块 (lexer.py)

**TokenType枚举**：定义所有Token类型
```
INT, FLOAT, BOOL          // 类型关键字
IF, ELSE, WHILE           // 控制流关键字
BREAK, CONTINUE, RETURN   // 跳转关键字
TRUE, FALSE               // 布尔字面量
IDENTIFIER                // 标识符
INT_LITERAL, FLOAT_LITERAL // 数值字面量
PLUS, MINUS, STAR, SLASH  // 算术运算符
EQ, NE, LT, LE, GT, GE    // 关系运算符
AND, OR, NOT              // 逻辑运算符
LPAREN, RPAREN, LBRACE... // 分隔符
```

**Lexer类**：
- `tokenize()` → 主入口，返回Token列表
- `read_number()` → 识别整数和浮点数
- `read_identifier()` → 识别标识符和关键字
- `skip_comment()` → 跳过单行和多行注释

#### 4.2.2 AST节点定义 (ast_nodes.py)

```
ASTNode (基类)
├── Program            // 程序节点
├── VarDecl            // 变量声明
├── FuncDecl           // 函数声明
├── Block              // 语句块
├── IfStmt             // if语句
├── WhileStmt          // while语句
├── ReturnStmt         // return语句
├── BreakStmt          // break语句
├── ContinueStmt       // continue语句
├── ExprStmt           // 表达式语句
├── BinaryExpr         // 二元表达式
├── UnaryExpr          // 一元表达式
├── AssignExpr         // 赋值表达式
├── CallExpr           // 函数调用
├── ArrayAccess        // 数组访问
├── Identifier         // 标识符
├── IntLiteral         // 整数字面量
├── FloatLiteral       // 浮点字面量
└── BoolLiteral        // 布尔字面量
```

#### 4.2.3 语法分析模块 (parser.py)

**文法设计（消除左递归后的LL(1)文法）**：
```
program      → declaration*
declaration  → varDecl | funcDecl | statement
varDecl      → type IDENTIFIER ('[' INT ']')? ('=' expr)? ';'
funcDecl     → type IDENTIFIER '(' params? ')' block
params       → param (',' param)*
param        → type IDENTIFIER
block        → '{' declaration* '}'
statement    → ifStmt | whileStmt | returnStmt | breakStmt 
             | continueStmt | block | exprStmt
ifStmt       → 'if' '(' expr ')' statement ('else' statement)?
whileStmt    → 'while' '(' expr ')' statement
returnStmt   → 'return' expr? ';'
exprStmt     → expr ';'

expr         → assignment
assignment   → orExpr ('=' assignment)?
orExpr       → andExpr ('||' andExpr)*
andExpr      → equality ('&&' equality)*
equality     → comparison (('==' | '!=') comparison)*
comparison   → additive (('<' | '<=' | '>' | '>=') additive)*
additive     → multiplicative (('+' | '-') multiplicative)*
multiplicative → unary (('*' | '/' | '%') unary)*
unary        → ('!' | '-') unary | primary
primary      → INT_LITERAL | FLOAT_LITERAL | 'true' | 'false'
             | IDENTIFIER ('(' args? ')')? | IDENTIFIER '[' expr ']'
             | '(' expr ')'
```

#### 4.2.4 符号表模块 (symbol_table.py)

**Symbol类**：存储符号信息
```python
@dataclass
class Symbol:
    name: str           # 符号名
    sym_type: str       # 类型
    scope_level: int    # 作用域层级
    is_array: bool      # 是否数组
    array_size: int     # 数组大小
    is_function: bool   # 是否函数
    params: List        # 函数参数
```

**SymbolTable类**：链式作用域栈
- `enter_scope()` → 进入新作用域
- `exit_scope()` → 退出当前作用域
- `define()` → 定义新符号
- `lookup()` → 查找符号（向上查找所有作用域）
- `dump()` → 输出符号表

#### 4.2.5 语义分析模块 (semantic.py)

**SemanticAnalyzer类**：
- 检查未定义变量/函数
- 检查重复定义
- 检查break/continue是否在循环中
- 检查函数调用参数个数
- 检查数组访问

#### 4.2.6 TAC生成模块 (tac_generator.py)

**三地址码指令格式**：
```
result = arg1 op arg2    // 二元运算
result = op arg1         // 一元运算
result = arg1            // 赋值
IFFALSE cond GOTO label  // 条件跳转
GOTO label               // 无条件跳转
LABEL label:             // 标签
CALL func, argc          // 函数调用
RETURN value             // 返回
ARG value                // 参数传递
```

#### 4.2.7 C代码生成模块 (codegen_c.py)

**CCodeGenerator类**：
- 直接遍历AST生成C代码
- 保持代码结构与源代码一致
- 自动添加必要的头文件

### 6.2 TAC输出示例
```
FUNC factorial:
  PARAM n
  t1 = n <= 1
  IFFALSE t1 GOTO L1
  RETURN 1
L1:
  t2 = n - 1
  ARG t2
  t3 = CALL factorial, 1
  t4 = n * t3
  RETURN t4
ENDFUNC factorial
FUNC main:
  ARG 5
  t5 = CALL factorial, 1
  result = t5
  RETURN result
ENDFUNC main
```

## 八、实验中遇到的困难及解决方法

1. **文法左递归问题**
   - 问题：表达式文法存在左递归，导致递归下降解析器无限递归
   - 解决：将左递归改写为右递归，使用优先级爬升法处理运算符优先级

2. **短路求值实现**
   - 问题：逻辑与/或需要短路求值
   - 解决：在TAC生成时使用条件跳转实现短路逻辑

3. **作用域管理**
   - 问题：变量在嵌套作用域中的正确查找
   - 解决：使用链式作用域栈，从内向外查找变量

## 九、心得体会

通过本次实验，深入理解了编译器的完整工作流程：

1. **词法分析**：将字符流转换为有意义的Token序列，正则表达式和有限自动机是核心理论基础

2. **语法分析**：基于上下文无关文法构造AST，递归下降是最直观的实现方式

3. **语义分析**：符号表管理是关键，作用域规则决定了变量的可见性

4. **代码生成**：三地址码作为中间表示，屏蔽了源语言和目标语言的差异

5. **工程实践**：模块化设计使得各阶段可以独立开发和测试

本编译器虽然简单，但涵盖了编译原理的核心概念，为进一步学习LLVM等工业级编译器框架打下了基础。

## 使用方法

```bash
# 生成AST
python src/compiler.py tests/test1_factorial.src -emit-ast

# 生成三地址码
python src/compiler.py tests/test1_factorial.src -emit-tac

python src/compiler.py tests/test1_factorial.src -o output.c

# 编译并运行
gcc -o output output.c && ./output
```
