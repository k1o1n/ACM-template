Repunit模板 - 找到由1组成且被n整除的数

问题描述：
对于任意正整数n，找到一个数，它的前部分由1组成，后部分由0组成，且一定为n的倍数。

理论基础（鸽巢原理）：
对于n，取出1、11、111、1111、……n+1个数，其中必有数在模n的情况下同余，取出这两个数做差，得到的数必定为n的倍数。

算法实现：

方法1：暴力模拟（适用于小数据）
#include<iostream>
using namespace std;

// 找到最小的由1组成的数，使其能被n整除
long long findRepunit(int n) {
    long long num = 0;
    for (int i = 1; i <= n; i++) {
        num = num * 10 + 1;
        if (num % n == 0) {
            return num;
        }
    }
    return -1;  // 理论上不会到达这里
}

int main() {
    int n;
    cin >> n;
    cout << findRepunit(n) << endl;
    return 0;
}

方法2：使用模运算优化（避免大数溢出）
#include<iostream>
using namespace std;

// 找到最小的由1组成的数能被n整除，返回该数有多少位
int findRepunitLength(int n) {
    int remainder = 0;
    for (int i = 1; i <= n; i++) {
        remainder = (remainder * 10 + 1) % n;
        if (remainder == 0) {
            return i;
        }
    }
    return -1;
}

int main() {
    int n;
    cin >> n;
    int length = findRepunitLength(n);
    cout << "最小repunit长度: " << length << endl;
    // 输出该数（如果长度不太大）
    if (length > 0 && length <= 18) {
        for (int i = 0; i < length; i++) {
            cout << "1";
        }
        cout << endl;
    }
    return 0;
}

方法3：使用鸽巢原理（更优雅的实现）
#include<iostream>
#include<unordered_map>
using namespace std;

// 利用鸽巢原理找到repunit
pair<int, int> findRepunitPair(int n) {
    unordered_map<int, int> seen;  // 存储余数及其首次出现的位置
    int remainder = 0;
    
    for (int i = 1; i <= n + 1; i++) {
        remainder = (remainder * 10 + 1) % n;
        
        if (remainder == 0) {
            return {i, i};  // 找到了直接能被n整除的repunit
        }
        
        if (seen.count(remainder)) {
            // 找到了两个同余的repunit，它们的差是n的倍数
            return {seen[remainder], i};
        }
        
        seen[remainder] = i;
    }
    
    return {-1, -1};
}

int main() {
    int n;
    cin >> n;
    
    auto result = findRepunitPair(n);
    cout << "第" << result.first << "个到第" << result.second << "个repunit的差是" << n << "的倍数" << endl;
    
    return 0;
}

应用场景：
1. 数论问题中的同余计算
2. 找到特定形式的倍数
3. 鸽巢原理的实际应用

时间复杂度：O(n)
空间复杂度：方法1和2为O(1)，方法3为O(n)

注意事项：
1. 对于大数n，可能需要输出的repunit位数很多，需要考虑输出方式
2. 使用模运算可以避免整数溢出
3. 某些特殊的n值（如2和5的倍数）可能需要特殊处理
